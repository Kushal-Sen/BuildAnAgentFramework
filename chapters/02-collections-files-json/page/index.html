Collections, files, JSON and errors

Hold groups of data, save them to files, and handle problems without crashing.

Where we are

Real programs work with groups of data

In chapter 01, you learned values, decisions, loops and functions. Now you’ll hold groups of data, then save and load them.

This matters for agents too. An agent’s whole conversation is a list of dictionaries, and models ask for tools using JSON. Open chapters/02-collections-files-json/code/data_basics.py and follow along.

Walkthrough

From values to saved data

  1. Lists and dictionaries

    A list holds values in order, and positions start at 0. A dictionary stores values under keys. order["product"] needs the key to exist, while order.get("discount", 0) gives back a default if it’s missing. A list of dictionaries is exactly how you’ll store an agent’s conversation.

  2. Files and JSON

    Path reads and writes files, and write_text replaces what’s in the file. JSON is a text format for data: json.loads turns text into Python data, and json.dumps turns Python data into text.

  3. Handling errors

    Some errors are expected, like a missing file. try runs the risky code, and except handles one kind of error. Agents use this same pattern: a tool’s error goes back as text, so the model can try something else. Only catch errors you expect, because a plain except: hides real bugs.

Common mistakes

  • Starting from 1 instead of 0. The last item in a list of 3 is at position 2.
  • Using [] for a key that might be missing. Use .get() instead.
  • Mixing up loads and dumps. Text goes in to loads, and text comes out of dumps.
  • Writing JSON with single quotes.
